## Performance Benefits

1. **React.memo on FileTreeItem**:
   - Prevents re-renders when props haven't changed
   - Particularly beneficial for large file trees where only one item changes
   - Child items won't re-render when parent expands/collapses (if props unchanged)

2. **useCallback on handlers**:
   - Callbacks maintain stable references across renders
   - Essential for React.memo to work effectively
   - Prevents child FileTreeItem components from receiving new function references on every parent render
