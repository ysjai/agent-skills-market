## 我的诉求

我想做 agent skill 的一些社交性功能，我有一些idea，在下面的清单中列出来。

### ideas清单

### 平台全网共享功能

- 共享的范围分为组织级别和平台级别
- 任何用户都可以共享自己的skill到平台
- 用户共享到平台的skill需要选定类别标签
- 类别标签是平台预先定义好的，用户在共享skill时需要选择一个类别
- 任何用户都可以搜索和查阅共享到平台的skill，搜索时可以根据skill名称、类别标签等进行筛选

### 组织共享功能

- 每个组织有创建者，创建者可以分配多个管理员来帮助管理组织
- 组织创建者和管理员可以邀请组织平台用户加入自己的组织
- 用户会收到邀请邮件，邀请邮件中包含加入组织的链接，申请链接要有有效期，过期后用户不能申请加入组织
- 用户可以在平台看到和搜索所有的组织，并且可以主动申请加入组织
- 组织的创建人和管理员可以审批申请，同意或者拒绝用户加入组织
- 加入组织的用户可以共享自己的skill到组织
- 组织的所有人可以查看组织内所有共享的skill


### 收藏和点赞功能

- 用户可以收藏skill，收藏的skill可以在我的收藏页面看到
- 用户也可以取消收藏skill
- 用户觉得某个skill很好，可以对该skill点赞，每个用户只能对某个skill点赞一次，用户每点赞一次会增加一个Skill的点赞数量。
- 用户也可以取消对某个skill的点赞，取消点赞后会减少Skill的点赞数量。
- 用户可以在我的收藏页面看到所有收藏的skill，以及每个skill的点赞数量。
- 当共享的skill被主人取消共享时，所有收藏该skill的用户的收藏记录不会被删除，会记录用户取消共享前的快照，用户可以在快照中查看该skill的详细信息，但是会提示用户该skill已被取消共享。用户可以选择取消收藏或不做处理。
- 当共享的skill被主人删除时，所有收藏该skill的用户的收藏记录不会被删除，会记录用户删除前的快照，用户可以在快照中查看该skill的详细信息，但是会提示用户该skill已被删除，用户可以选择取消收藏或不做处理。

### 分享达人成就勋章

- 平台会根据用户的分享情况，评选出一些分享达人，这些用户会获得平台的成就勋章
- 分享达人的评选标准包括但不限于：分享的skill数量、收到的点赞数量、收到的收藏数量
- 分享达人勋章会存在多个等级，每个等级有不同的标准，比如：普通分享达人、活跃分享达人、专业分享达人等
- 分享达人的评选会定期进行，评选结果会在平台上展示，用户也可以在个人资料中查看自己的分享达人勋章
